MOHAN P — MULTI-PAGE PORTFOLIO
================================

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension if you do not already have it.
4. Right-click index.html and select "Open with Live Server".

PROFILE PHOTO (HOMEPAGE)
- Add your own professional photo to the assets folder.
- Rename it exactly: profile.jpg
- The homepage will show it in the profile-photo area.
- Use a square image (recommended 600 x 600 px or larger).
- I cannot reliably fetch and embed your LinkedIn profile photo automatically. Upload the photo here and I can place/crop it correctly.

RESUME
- Add your separate one-page resume PDF to assets/
- Rename it exactly: resume.pdf
